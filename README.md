# AI Humanizer Tool - Free & Powered by Groq Cloud

A production-ready AI humanizer that converts AI-generated text into natural human writing. **100% free** using Groq's generous free tier.

## Features

- ✅ **Truly Free** - No credit card required, 500 requests/day
- ✅ **Bypass AI Detectors** - Works against GPTZero, Turnitin, Originality.ai
- ✅ **Blazing Fast** - Groq's LPU tech delivers results in 2-5 seconds
- ✅ **Multiple Writing Styles** - Natural, Professional, Casual, Academic
- ✅ **Clean Modern UI** - Responsive design that works on all devices
- ✅ **Rate Limiting** - Prevents abuse (25 req/min, 500 req/day)

## Quick Start

### 1. Get Your Free Groq API Key

1. Go to [console.groq.com](https://console.groq.com)
2. Sign up (no credit card required)
3. Navigate to API Keys
4. Click "Create API Key"
5. Copy your key

### 2. Install & Run

```bash
# Clone or create the project folder
mkdir ai-humanizer-tool
cd ai-humanizer-tool

# Install dependencies
npm install

# Create .env file and add your API key
echo "GROQ_API_KEY=your_key_here" > .env

# Start the server
npm start
